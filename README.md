# آرشیو نشاط زندگی

وب‌سایت عمومی و مستقل برای مرور مطالبی که بیش از ۷ روز از تاریخ انتشارشان گذشته است.

## ویژگی‌ها

- نمایش فقط مطالب منتشرشده با `is_published = true` و تاریخ انتشار قدیمی‌تر از ۷ روز
- مرتب‌سازی نزولی بر اساس `published_at`
- دسته‌بندی با جداول موجود `categories` و `subcategories` (بنر مستقل بازی‌ها از فهرست مطالب حذف است)
- جست‌وجو در عنوان و متن
- صفحه‌بندی سمت سرور (۱۲ مطلب در هر صفحه)
- نمایش عنوان، متن کامل، تاریخ انتشار و منبع
- بدون نیاز به حساب کاربری یا ورود

## اتصال Supabase

تنظیمات عمومی اتصال در `config.js` قرار دارد. این فایل فقط از Publishable key استفاده می‌کند. **هرگز `service_role` یا Secret key را در کد سمت کاربر قرار ندهید.**

سایت فقط درخواست‌های GET به جداول موجود `contents`، `categories` و `subcategories` می‌فرستد. هیچ عملیات درج، ویرایش یا حذف در سایت وجود ندارد.

آرشیو بر مبنای `published_at` محاسبه می‌شود. مطالبی که `published_at` ندارند وارد آرشیو نمی‌شوند تا تاریخ انتشار حدس زده نشود.

### نکته ساختار فعلی پایگاه داده

در طرح فعلی، برای `contents.category_id` و `contents.subcategory_id` کلید خارجی تعریف نشده است؛ بنابراین سایت دسته‌ها و مطالب را جداگانه می‌خواند و با شناسه‌های موجود تطبیق می‌دهد. هیچ تغییر ساختاری در پایگاه داده انجام نشده است.

## انتشار روی Cloudflare Pages

1. در Cloudflare وارد **Workers & Pages → Create → Pages** شوید.
2. گزینه **Import an existing Git repository** را انتخاب کنید.
3. مخزن `javad1371/neshat-zendegi-archive` را متصل کنید.
4. Framework preset را روی **None** بگذارید.
5. Build command را خالی بگذارید.
6. Build output directory را `.` قرار دهید.
7. Deploy را اجرا کنید.

این پروژه استاتیک است و به نصب Node.js، دستور build، تابع سرور یا سرویس پولی نیاز ندارد.

## نگهداری

- آستانه ۷ روز در `app.js` و ثابت `ARCHIVE_AGE_DAYS` تعریف شده است.
- تعداد مطالب هر صفحه در `PAGE_SIZE` مشخص است.
- سایت آرشیو را یک‌جا دانلود نمی‌کند؛ فقط صفحه درخواستی از Supabase دریافت می‌شود.
- برای تغییر ظاهر، `styles.css` را ویرایش کنید.

## وضعیت

نسخه اولیه آماده اتصال به Cloudflare Pages است. پس از استقرار، باید درخواست‌های عمومی مرورگر و تعداد مطالب آرشیو با داده‌های واقعی پروژه آزمایش شوند.
